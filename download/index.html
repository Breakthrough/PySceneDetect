Download

PySceneDetect is free, open-source software released under the BSD 3-Clause License (see License & Copyright). If you have trouble running PySceneDetect, verify that you have the packages listed under Dependencies.

Windows Build (64-bit Only)

Windows 64-bit · v0.7.3 November 8, 2026
Installer .msi Recommended Portable .zip

The .msi installer is recommended for most Windows users. Both Windows builds bundle ffmpeg. To use split-video -m, install MKVToolNix. After installing, see the Command-Line Interface guide to get started.

Install with pip, uv, or pipx

Installing from PyPI requires Python 3.10 or newer.

Standard install with pip (CLI and Python API):

pip install --upgrade scenedetect

Headless install (for servers and containers without GUI libraries):

pip install --upgrade scenedetect-headless

Install with uv or pipx:

# uv (isolated CLI tool)
uv tool install scenedetect

# uv (add to a Python project)
uv add scenedetect

# pipx (isolated CLI tool)
pipx install scenedetect

PySceneDetect is published on PyPI as two packages, both including the CLI and the scenedetect Python module:

  • scenedetect: depends on opencv-python.
  • scenedetect-headless: depends on opencv-python-headless.

Install only one of them.

Docker Image

Official container images are published on GitHub Container Registry at ghcr.io/breakthrough/pyscenedetect. Each image includes the CLI, all optional video backends (PyAV and MoviePy), ffmpeg, and mkvmerge:

docker pull ghcr.io/breakthrough/pyscenedetect
docker run --rm ghcr.io/breakthrough/pyscenedetect version

To process videos, mount the folder that holds them into the container. The container runs as a non-root user, so output files keep normal permissions:

docker run --rm -v "$(pwd):/files" ghcr.io/breakthrough/pyscenedetect \
    -i /files/video.mp4 detect-adaptive split-video -o /files

The latest tag points to the most recent stable release, main tracks the development branch, and version tags (such as 0.7.3) point to specific releases. You can also replace docker with podman in the commands above.

Post-Installation Check

After installing, open a terminal and run scenedetect version or scenedetect --help. If you see an import error, verify that import numpy and import cv2 work in Python and review Dependencies.

If you find a bug or want to suggest a feature, open an issue on the issue tracker or see Contributing & Support.

Dependencies

Python packages

The scenedetect and scenedetect-headless packages install these dependencies automatically:

  • OpenCV: pip install opencv-python (or opencv-python-headless with scenedetect-headless)
  • NumPy: pip install numpy
  • Click: pip install click (used by the CLI)
  • tqdm: pip install tqdm (displays progress bars)
  • platformdirs: pip install platformdirs (used by the CLI)

Optional video backend packages:

  • PyAV: pip install av (or pip install "scenedetect[pyav]")
  • MoviePy: pip install moviepy (or pip install "scenedetect[moviepy]")

Video splitting tools

To split videos into clips, install at least one of these tools (ffmpeg is bundled in the Windows builds; the Docker image has both):

  • FFmpeg: splits videos with re-encoding (split-video) or stream copy (split-video -c / --copy).
  • MKVToolNix (mkvmerge): splits videos in stream-copy mode (split-video -m / --mkvmerge).

See Video Splitting Requirements for installation and PATH setup steps.

Building OpenCV from source

If you installed OpenCV with pip, uninstall it before installing a different OpenCV build or compiling from source. See the Installing OpenCV guide for steps on Windows and Linux.

To verify your setup, open a Python prompt and run import numpy and import cv2.
