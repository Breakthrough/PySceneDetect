Latest release v0.7.3 · Nov 8, 2026

Fast, frame-accurate scene cut detection for video.

Detect fast cuts and fades from the command line or Python. Split videos with ffmpeg or mkvmerge, export timeline files for video editors, or save per-frame metrics.

Get Started Documentation
Download
Install
$ pip install --upgrade scenedetect
$ uv tool install scenedetect
$ pipx install scenedetect
Example

Split a video at each detected cut

scenedetect -i goldeneye.mp4 split-video

Export a CSV scene list, still frames, and an HTML report

scenedetect -i goldeneye.mp4 list-scenes save-images save-html

Find scene cuts and split the video with ffmpeg

from scenedetect import (
    detect, AdaptiveDetector, split_video_ffmpeg,
)

scenes = detect("goldeneye.mp4", AdaptiveDetector())
split_video_ffmpeg("goldeneye.mp4", scenes)

Five Detectors

Choose from Adaptive, Content (HSV and edges), Perceptual Hash, Histogram, and Threshold detectors. All five are tested on BBC Planet Earth, AutoShot, and ClipShots.

Standard Export Formats

Export HH:MM:SS.nnn CSV scene lists, CMX 3600 EDL, Final Cut Pro XML, OpenTimelineIO (OTIO), x264 QP files, HTML reports, and still frames.

save-edl · save-otio · save-images · More export formats

Modular Video Backends

Common Use Cases

People use PySceneDetect for many video workflows:

  • Splitting home videos or raw footage into separate scene clips.
  • Finding and removing commercials from recorded TV broadcasts.
  • Reviewing and splitting security camera recordings.
  • Finding clean loops in videos for GIFs and cinemagraphs.
  • Analyzing film and video datasets, such as measuring average shot length.

Download PySceneDetect to try it on your own videos, or review the Features page for a full list of detectors and export formats. The default timecode format (HH:MM:SS.nnn) works directly with tools such as ffmpeg and mkvmerge.
